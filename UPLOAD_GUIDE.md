# Hướng dẫn đưa gói lên GitHub

Gói này là snapshot đầy đủ của repository tại thư mục `Reading_Companion/`. Nó chưa được commit hoặc push.

1. Tải `Reading_Companion-0.3.3-github.zip` và giải nén.
2. Mở bản clone repository `Nohfinl99/Reading_Companion` hoặc fork của bạn. Giữ nguyên thư mục `.git` của bản clone.
3. Sao chép **nội dung bên trong** `Reading_Companion/` vào root repository và chấp nhận cập nhật các file trùng tên. Giữ cả thư mục ẩn `.github/` và `.codex-plugin/`. Không lồng thêm một thư mục `Reading_Companion/` bên trong root repository.
4. Xem diff để xác nhận identity/manifest, helper scripts, license và file benchmark. Chạy lại các lệnh trong README.
5. Dùng GitHub Desktop hoặc workflow Git của bạn để chọn branch, review, commit và push. Các bước đó do bạn thực hiện; ZIP này không thay đổi repository trên GitHub.
